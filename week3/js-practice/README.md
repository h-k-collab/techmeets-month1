# js-practice

JavaScriptの基礎（変数・オブジェクト・配列・関数・DOM操作）を使って、ショッピングカートの合計金額を計算するページを作成しました。

## ファイル

- `practice.html` … 商品一覧をテーブルで表示し、ボタンを押すと税込合計を計算して表示する

## 学び・気づき

- `const` と `let` を自在に使い分けられると便利。
  - 変更しない値（消費税率 `TAX_RATE` など）は `const`
  - 後から更新する値（合計金額 `totalPrice` など）は `let`
- 値が変わっても、同じ関数（`calcTotal`）を呼び出すだけで計算できる。
- 商品名や値段が変わったときも、`const` の商品リスト（`cartItems`）に書き加えるだけでOK。表示や計算の処理を書き直す必要がない。
