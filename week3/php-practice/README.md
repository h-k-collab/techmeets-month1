# PHP練習

## 問題点
- `comment.php` で名前の判定に代入演算子 `=` が使われており、条件分岐が正しく機能していなかった（本来は比較演算子 `===` が必要）
- 出力時にXSS対策（`htmlspecialchars`）がされていなかった
- 空のコメントでも投稿できてしまっていた

## 修正した内容
- name の代入演算子 `=` を比較演算子 `===` に変更し、空白のみの入力もはじけるように `trim()` を追加
- `htmlspecialchars()` でエスケープしてから出力することでXSS対策を追加
- コメントも空かどうかのチェックを追加し、空のコメントが投稿できないようにした
- 修正版は `comment_fixed.php` に保存し、`comment.php` は元のコードのまま残している
