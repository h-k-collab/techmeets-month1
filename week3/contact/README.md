# お問い合わせフォーム

## 概要
名前・メールアドレス・件名・メッセージを入力するお問い合わせフォーム。`contact.php` 1ファイルで完結する。

## 機能
- 入力項目: 名前、メールアドレス、件名、メッセージ
- バリデーション: 全項目必須チェック、メールアドレスの形式チェック（`filter_var` + `FILTER_VALIDATE_EMAIL`）
- XSS対策: 出力時はすべて `htmlspecialchars` でエスケープ
- 送信成功時は入力内容を確認画面として表示

## 実行方法
```
php -S localhost:8000
```
起動後、`http://localhost:8000/contact.php` にアクセスする。

## 工夫した点
- 入力場所を明確に分け、欄が分かりやすいようにした
- 1カ所でも入力できていない場所があると、送信できないようにした
- コードにコメント説明を足し、内容をより分かりやすくした

## 学んだこと
- 0→8, 9まではAIに作らせて良いが、最後の10までは自分で確かめて改善する必要がある
- 自分の思い描いていることは細かく伝える必要がある
- その他セキュリティ対策にも注意する必要がある
